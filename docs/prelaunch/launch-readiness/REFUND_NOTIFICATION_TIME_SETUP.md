# 退款通知完成时间

2026-10-01。使用既有真实退款通知开关、原始body验签与解密路径，无新增开关或schema。

成功通知的success_time可选；存在时严格解析为UTC，格式错误拒绝通知，缺失保持未知。仅通知身份和金额与退款指令一致时，同一事务记录独立wechat-refund-time-notify-v11事件、原查询触发、审计和恢复任务后确认接收。通知事件本身不完成退款资金，也不释放预算或改变成员资格。

独立时间事件绑定退款指令、原收款、金额、CNY及provider配置。审计关联原已验签通知事件和验证材料ID。通知时间与查询时间使用同一退款编号的事务锁，防止并发检查遗漏。变更时间、早于收款、未来超容差或来源间冲突保留MANUAL事件和处理case；不能以之后恢复原值自动解除。

账期消费接受独立通知时间或独立查询时间。两种来源同时存在时，必须都是唯一APPLIED事件且精确payload/hash/配置/金额/归属/时间一致。任一冲突保持账期未覆盖。CSV、通知触发事件和本地updatedAt不能充当完成时间。整体账单范围仍INCOMPLETE，无发布权力。
